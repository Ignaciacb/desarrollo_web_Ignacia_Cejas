\# Tarea 2 - Desarrollo Web



\## Descripción

Esta tarea incluye la implementación de una pagina web de adopciones de mascotas, usando las siguientes herramientas: HTML, CSS. JavaScript, Python (Jinja2), Flask y SQLAlchemy.



\## Observaciones

* Para activar el venv, primero hay que moverse a Adopciones y luego a flask\_app, una vez estes en esta ruta, el venv se puede activar y puedes correr la app.
* En Adopciones -> flask\_app -> static -> js, se encuentran los codigos en javascript de la tarea pasada, app.js se encuentra exactamente igual, mientras que validation.js lo modifique para usarlo en esta tarea
* Cree un documento .html para cada una de las secciones de la pagina, incluyendo para la pagina en la que aparece el mensaje de éxito.



&nbsp;	Portada -> index.html 

&nbsp;	Agregar aviso -> agregar\_aviso.html

&nbsp;	Ver listado -> lista.html

&nbsp;	Detalle del aviso -> detalles.html

&nbsp;	Estadísticas -> estadisticas.html 

&nbsp;	Mensaje de éxito -> éxito.html

&nbsp;	Estructura común -> base.html



* Para seleccionar mas de una imagen, debes mantener presionado ctrl + shift y clickear todas las que quieres agregar o clickear el cuadrito blanco que aparece sobre cada imagen.
